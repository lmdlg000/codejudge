# P4 日期推算

## 题目背景

排班系统只知道一个起始日期和要往后推的天数。请算出推算后的日期。注意闰年：能被 4 整除且不能被 100 整除的年份是闰年，能被 400 整除的年份也是闰年；闰年的 2 月有 29 天。

## 输入格式

一行一个日期和一个整数，格式为 `YYYY-MM-DD D`，表示起始日期和要推算的天数。

## 输出格式

一行一个日期，格式为 `YYYY-MM-DD`，表示推算结果。注意月和日不足两位时补前导零。

## 样例输入

```
2025-01-01 0
```

## 样例输出

```
2025-01-01
```

## 样例输入 2

```
2025-01-01 31
```

## 样例输出 2

```
2025-02-01
```

## 样例输入 3

```
2024-02-28 1
```

## 样例输出 3

```
2024-02-29
```

## 样例输入 4

```
2025-12-31 1
```

## 样例输出 4

```
2026-01-01
```

## 样例输入 5

```
2024-01-01 365
```

## 样例输出 5

```
2024-12-31
```

## 数据范围

- `1900-01-01 ≤ 起始日期 ≤ 2100-12-31`
- `0 ≤ D ≤ 1000000`
- 起始日期与推算结果均保证合法。
