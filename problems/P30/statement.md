# P30 勾股数计数

> 难度：中等 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 2000ms / 256MB
> 题源：情境拓展 ·《趣味数学及编程拓展》1.4.1 勾股数。本题题面自包含，无需查阅原卷。

## 题目背景

满足 a² + b² = c² 的三个正整数 (a, b, c) 称为一组勾股数（毕达哥拉斯三元组），例如 (3,4,5)、(5,12,13)。中国古算书《周髀算经》中就有"勾三股四弦五"的记载。

给定上限 n，请统计满足 1 ≤ a < b < c ≤ n 的勾股数组数。

## 输入格式

一行，一个整数 n（1 ≤ n ≤ 500）。

## 输出格式

一行，一个整数，表示满足条件的勾股数组数。

## 样例输入

```
13
```

## 样例输出

```
3
```

样例说明：n = 13 时有三组：(3,4,5)、(6,8,10)、(5,12,13)。

## 样例输入 2

```
20
```

## 样例输出 2

```
6
```

样例说明：n = 20 时比 n = 13 多出 (8,15,17)、(9,12,15)、(12,16,20)，共 6 组。

## 样例输入 3

```
5
```

## 样例输出 3

```
1
```

样例说明：只有 (3,4,5) 一组。

## 数据范围

- 1 ≤ n ≤ 500

## 思路提示

两层循环枚举 a（1..n）和 b（a+1..n），算出 s = a²+b²，再从 c = 1 递增到 c² ≥ s，若 c² == s 且 c ≤ n 则计数。`a*a+b*b` 要用 long long 防止溢出。n = 500 时约 12.5 万次枚举，可以在时限内完成。

## 常见错误

1. 允许 a ≥ b 或 b ≥ c，导致同一组被重复计数。
2. 不限制 c ≤ n，把超出上限的组合也算进去。
3. 用 int 计算平方和导致溢出。
