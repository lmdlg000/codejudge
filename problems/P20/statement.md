# P20 区间素数计数

> 难度：中等 · 计分：ACM · **C++ 语言题**，单文件提交（main.cpp） · 构建：g++ -O2 -std=c++17 · 时限 1000ms / 256MB
> 题源：C++ 历年试卷编程题改编。本题题面自包含，无需查阅原卷。

## 题目背景

素数（质数）是大于 1 且只能被 1 和自身整除的整数。统计某个编号区间内有多少个素数，是哈希分桶、参数筛选等场景中的常见需求。

给定闭区间 [l, r]，请统计其中素数的个数。

## 输入格式

一行，两个整数 l 和 r（0 ≤ l ≤ r ≤ 100000）。

## 输出格式

一行，一个整数，表示闭区间 [l, r] 内素数的个数。

## 样例输入

```
1 10
```

## 样例输出

```
4
```

样例说明：[1,10] 内的素数是 2、3、5、7，共 4 个；注意 1 不是素数。

## 样例输入 2

```
10 20
```

## 样例输出 2

```
4
```

样例说明：[10,20] 内的素数是 11、13、17、19。

## 样例输入 3

```
2 2
```

## 样例输出 3

```
1
```

## 数据范围

- 0 ≤ l ≤ r ≤ 100000

## 思路提示

使用埃拉托斯特尼筛法：建一个长度 r+1 的布尔数组并全部置为 true，再把下标 0、1 置为 false；从 i = 2 遍历到 i×i ≤ r，若 i 仍为 true，就从 i×i 开始、步长 i 把后面所有倍数标记为 false。最后统计下标从 max(l, 2) 到 r 之间为 true 的个数。

## 常见错误

1. 把 0 或 1 误当作素数。
2. 筛的起点写成 `i*2` 而不是 `i*i`，结果虽对但会明显变慢。
3. l = 0 时直接从下标 l 开始统计，处理 0、1 不当。
