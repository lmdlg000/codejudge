# P1 运费计算

## 题目背景

快递点按重量收运费：首重 1000 克及以内收 10 元；超出部分每 500 克加收 3 元，不足 500 克按 500 克算。另外按派送距离加收附加费：500 公里以内免收，500 公里以上至 1000 公里加收 5 元，超过 1000 公里加收 12 元。请根据包裹重量和派送距离算出总运费。

## 输入格式

一行两个整数 `w` 和 `d`，分别表示包裹重量（克）和派送距离（公里）。

## 输出格式

一行一个整数，表示总运费（元）。

## 样例输入

```
800 300
```

## 样例输出

```
10
```

## 样例输入 2

```
1000 500
```

## 样例输出 2

```
10
```

## 样例输入 3

```
1500 800
```

## 样例输出 3

```
18
```

## 样例输入 4

```
2300 1200
```

## 样例输出 4

```
31
```

## 样例输入 5

```
5000 1000
```

## 样例输出 5

```
39
```

## 数据范围

- `1 ≤ w ≤ 100000`
- `1 ≤ d ≤ 3000`
- 运费保证在 32 位有符号整数范围内。
