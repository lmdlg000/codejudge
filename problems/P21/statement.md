# P21 字符查找

> 难度：简单 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：C 语言题库 2015 编程题改编。本题题面自包含，无需查阅原卷。

## 题目背景

在一段文本里定位某个字符第一次出现的位置，是字符串处理的基本操作，比如查找分隔符、校验标记位。

给定字符串 s 和字符 c，请找出 c 在 s 中第一次出现的位置。

## 输入格式

第一行：一个不含空格的字符串 s（1 ≤ |s| ≤ 255）。
第二行：一个字符 c，可以是字母、数字或空格。

## 输出格式

一行，一个整数：c 在 s 中第一次出现的位置，**从 1 开始计数**；若 s 中不含 c，输出 0。

大小写敏感，`A` 与 `a` 视为不同字符。

## 样例输入

```
hello
l
```

## 样例输出

```
3
```

样例说明：`h` 在第 1 位、`e` 在第 2 位，第一个 `l` 在第 3 位。

## 样例输入 2

```
abcdef
x
```

## 样例输出 2

```
0
```

## 样例输入 3

```
banana
a
```

## 样例输出 3

```
2
```

## 数据范围

- 1 ≤ |s| ≤ 255
- 输入保证 s 不含空格，c 为单个字符（可能是空格）

## 思路提示

用 `fgets` 读入第一行并去掉末尾换行符，再用 `getchar()` 读第二行的字符——这样即使 c 是空格也能正确读到。从左到右遍历 s，遇到第一个等于 c 的下标 i，输出 i+1（转成 1-based）；遍历结束仍未找到则输出 0。

## 常见错误

1. 输出 0-based 下标（`hello` 的 `l` 会输出 2 而不是 3）。
2. 用 `scanf("%c")` 读字符时，上一行残留的换行符被当成了 c。
3. 未找到时输出 -1 而不是题目要求的 0。
