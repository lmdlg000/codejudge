# P22 数组最大值

> 难度：简单 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：C 语言题库 2017 编程题改编。本题题面自包含，无需查阅原卷。

## 题目背景

从一组数据中找出最大值是最常见的统计操作，例如找出最高分、最高温度或最大流量。

给定 n 个整数，请输出其中的最大值。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 1000）。
第二行 n 个整数，用空格分隔。

## 输出格式

一行，一个整数，即这 n 个数中的最大值。

## 样例输入

```
10
1 9 7 4 8 3 2 5 6 15
```

## 样例输出

```
15
```

## 样例输入 2

```
5
-3 -1 -9 -2 -7
```

## 样例输出 2

```
-1
```

样例说明：全为负数时最大值是 -1，不是 0。

## 数据范围

- 1 ≤ n ≤ 1000
- 每个整数在 32 位有符号整数范围内

## 思路提示

先把第一个数读入并作为最大值初值，再依次读入剩下的 n-1 个数，遇到更大的就更新。不要用一个固定的小数（如 0）当初值，否则全负数输入会得到错误答案。

## 常见错误

1. 最大值初值设为 0，全负数时输出 0。
2. 循环从下标 1 开始但第一个数没有先读入。
3. n = 1 时循环体不执行，忘记输出唯一的元素。
