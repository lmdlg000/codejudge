# P24 对称方阵

> 难度：简单 · 计分：OI · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：C 语言题库 2022 秋完善题改编。本题题面自包含，无需查阅原卷。

## 题目背景

在图形化打印与图案题中，用二维数组画一个"X"形是经典练习：两条对角线上的位置填 1，其余填 0。

给定方阵阶数 n，请输出这样的 n 阶方阵。

## 输入格式

一行，一个整数 n（1 ≤ n ≤ 20）。

## 输出格式

输出 n 行，每行 n 个整数（0 或 1），同一行相邻整数之间用**一个空格**分隔，行末不要有多余空格。

位置 (i, j)（行、列均从 0 开始）满足以下任一条件时输出 1，否则输出 0：

- i == j（主对角线）；
- i + j == n - 1（副对角线）。

## 样例输入

```
5
```

## 样例输出

```
1 0 0 0 1
0 1 0 1 0
0 0 1 0 0
0 1 0 1 0
1 0 0 0 1
```

## 样例输入 2

```
3
```

## 样例输出 2

```
1 0 1
0 1 0
1 0 1
```

## 数据范围

- 1 ≤ n ≤ 20

## 思路提示

二重循环遍历 i、j，按上述两个条件算出值 v。用 `if (j) putchar(' ');` 在每行的第 2 列及以后先打一个空格再输出 v，这样行末不会留多余空格。判题用 trim 比对，行末空格会被忽略，但行内空格数量敏感。

## 常见错误

1. 只画了主对角线，漏掉副对角线。
2. 每个数字后面都跟一个空格（包括行末），写法不规范。
3. 误以为 n 为偶数时中心会重合——两条对角线只在 n 为奇数时相交于中心格。
