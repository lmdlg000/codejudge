# P24 元素查找

> 难度：简单 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：C 语言题库 2016 编程题改编。本题题面自包含，无需查阅原卷。

## 题目背景

判断某个编号或关键字是否存在于一批数据中，是查找操作的基本形式，例如检查某个学号是否在名单里。

给定 n 个整数和一个目标值 x，请判断 x 是否出现在这 n 个数中。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 1000）。
第二行 n 个整数，用空格分隔。
第三行一个整数 x，表示要查找的目标值。

## 输出格式

一行：若 x 在数组中至少出现一次，输出 `found`；否则输出 `not found`。全部小写，不要输出引号或标点。

## 样例输入

```
10
15 9 7 11 7 21 7 9 3 12
7
```

## 样例输出

```
found
```

## 样例输入 2

```
5
1 2 3 4 5
99
```

## 样例输出 2

```
not found
```

## 数据范围

- 1 ≤ n ≤ 1000
- 数组元素与目标值均在 32 位有符号整数范围内

## 思路提示

先把 n 个数存入数组，再读目标值，最后线性扫描一遍，遇到相等就置标志并提前结束。数组允许重复元素，找到任意一个即可。

## 常见错误

1. 边读数组边读目标值，导致目标值被当成数组元素。
2. 输出 `Found` / `Not found` 等大小写不一致的字符串——判题按字符精确比对。
3. 找到后仍继续扫描，虽然结果不变但浪费时间。
