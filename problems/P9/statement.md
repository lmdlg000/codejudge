# P9 区间规划器

> 难度：进阶 · 多文件 make 工程（恰好 4 个文件） · 构建：`make` → `planner` · 时限 2000ms / 256MB

## 题目背景

给定 n 个闭区间 [l, r] 与 q 个查询点 x，请在同一个程序里完成两件事：

1. 计算**最大两两不相交区间个数**（区间调度贪心：按右端点升序安排）。注意：**两区间共享端点即算相交**——[1,2] 与 [2,3] 不能同时选，[1,2] 与 [3,4] 可以同时选。
2. 对每个查询点 x，回答**有多少个区间包含 x**（l ≤ x ≤ r，端点算包含）。

n、q 最大 20 万，逐区间逐查询的 O(n·q) 扫描或 O(n²) 枚举都会超时，需要排序 + 二分把整体做到 O((n+q) log n) 量级。

本题考查：枚举与贪心（区间调度）、排序、二分检索、多文件工程组织（模块拆分 + makefile）。

## 输入格式

- 第 1 行两个整数 `n q`。
- 接下来 n 行，每行两个整数 `l r`，表示一个闭区间 [l, r]（0 ≤ l ≤ r ≤ 10^9）。
- 再接下来 q 行，每行一个整数 x（0 ≤ x ≤ 10^9）。

## 输出格式

- 第 1 行一个整数：最大两两不相交区间个数。
- 接下来 q 行，每行一个整数：第 j 行是第 j 个查询点 x_j 被多少个区间包含。


## 提交要求（多文件 make 工程）

多文件提交**恰好包含这 4 个文件**（文件名固定）：

| 文件 | 内容 |
| --- | --- |
| `interval.h` / `interval.C` | 区间排序与贪心（最大不相交区间数）模块 |
| `query.h` / `query.C` | 二分查询（查询点被包含计数）模块 |
| `main.C` | 主程序：读入、调用两个模块、按格式输出 |
| `makefile` | 构建规则（见下） |

- **`.h` 只放声明 + 头文件保护宏**（`#ifndef/#define/#endif`），实现全部放 `.C`；
- 每个 `.C` **首行 `#include` 对应的 `.h`**（如 `interval.C` 首行 `#include "interval.h"`）；
- 允许使用 STL 容器与 `<algorithm>`（本题考算法组织而非裸字符处理）；
- `makefile` 要求：`TARGET = planner`、`all` 生成 `planner`、`clean` 删除 `.o` 与 `planner`、`CXX = g++`、`CXXFLAGS = -std=c++20 -O2 -w -Wall`、每个 `.o` 写清依赖的 `.h`、**配方行以 Tab 缩进**（不是空格）、**不写死绝对路径**。参考模板（`$(CXX)`、`rm` 行前是 Tab）：

```makefile
CXX = g++
CXXFLAGS = -std=c++20 -O2 -w -Wall
OBJ = main.o interval.o query.o
TARGET = planner

all: $(TARGET)

$(TARGET): $(OBJ)
	$(CXX) $(CXXFLAGS) -o $(TARGET) $(OBJ)

main.o: main.C interval.h query.h
	$(CXX) $(CXXFLAGS) -c main.C

interval.o: interval.C interval.h
	$(CXX) $(CXXFLAGS) -c interval.C

query.o: query.C query.h interval.h
	$(CXX) $(CXXFLAGS) -c query.C

clean:
	rm -f $(OBJ) $(TARGET)

.PHONY: all clean
```

变量名与 `.o` 列表可自行调整，但行为必须满足：`make` 生成 `planner`、`make clean` 清干净 `.o` 与可执行文件、每个 `.o` 依赖写全对应的 `.h`。

## 样例输入

```text
4 3
1 3
2 5
4 6
7 8
2
4
7
```

## 样例输出

```text
3
2
2
1
```

## 样例说明

4 个区间 [1,3]、[2,5]、[4,6]、[7,8]，3 个查询点 2、4、7：

- 最大不相交：选 [1,3]、[4,6]、[7,8] 共 **3** 个（[2,5] 与 [1,3] 相交，与 [4,6] 也相交，不能选）；
- x=2：被 [1,3]、[2,5] 包含 → **2**；
- x=4：被 [2,5]、[4,6] 包含 → **2**；
- x=7：被 [7,8] 包含 → **1**。

## 实现提示

两个子问题互相独立，正好对应 `interval.*` 与 `query.*` 两个模块，可以分开实现、在 `main.C` 里各调一次。

**子问题 1：最大两两不相交区间数（区间调度贪心，5 步）**

1. 把 n 个区间读入结构体数组 `{l, r}`；
2. **按右端点 `r` 升序排序**（右端点相同再按 `l` 升序，保证结果确定）；
3. 维护"最后一个已选区间的右端点" `last`，初始取一个比所有 `l` 都小的值；
4. 按序扫描：若当前区间满足 **`l > last`**（严格大于——**共享端点即算相交**），则选中它、计数 +1、`last = r`；
5. 扫描结束的计数就是答案。

> 贪心正确性：每次选**右端点最小**的相容区间，给后面留下最多空间。按左端点排序、按区间长度排序都不对；右端点相同先按 `l` 排，只是让结果稳定，不影响计数。

**子问题 2：查询点 x 被多少个区间包含（排序 + 二分，4 步）**

1. 把所有**左端点** `l` 收进数组 `L[]` 升序排序，把所有**右端点** `r` 收进数组 `R[]` 升序排序；
2. 含 x 的区间数 = **（l ≤ x 的区间数）−（r < x 的区间数）**——前者是"已开始"的区间数，后者要减去"已结束"的区间数；
3. `l ≤ x` 的个数 = `upper_bound(L.begin(), L.end(), x)` 的下标（第一个 > x 的位置）；`r < x` 的个数 = `lower_bound(R.begin(), R.end(), x)` 的下标（第一个 ≥ x 的位置）；
4. 两值相减即答案，每次查询 **O(log n)**，总复杂度 O((n + q) log n)。

> 另一种等价写法：差分 + 前缀和（`add[l]++`、`add[r+1]--`），但 x 可达 10^9，必须先**离散化**坐标才能开数组；本题 n、q 都 20 万，二分法更省事、更不易错。

**关键边界与易错点**：

- **比较函数方向**：`sort` 的比较器必须满足**严格弱序**（不能写 `return a.r <= b.r`，含等号在部分实现下直接 UB）；按右端点排就写 `if (a.r != b.r) return a.r < b.r; return a.l < b.l;`；
- **相交判据是严格大于**：选下一个区间看 `l > last`，写成 `l >= last` 会把 [1,2] 与 [2,3] 误判为可共存；
- **二分别用混**：数 `l ≤ x` 用 `upper_bound`（第一个 > x 之前都算）、数 `r < x` 用 `lower_bound`（第一个 ≥ x 之前都算）；
- **端点算包含**：`l ≤ x ≤ r` 是闭区间，x 正好等于 l 或 r 都算被包含；
- **坐标 0~10^9**：不能拿坐标当下标开桶数组，必须走排序 + 二分（或离散化）。

## 数据范围

- 1 ≤ n ≤ 200000，1 ≤ q ≤ 200000
- 0 ≤ l ≤ r ≤ 10^9，0 ≤ x ≤ 10^9
- 共享端点即算相交：[1,2] 与 [2,3] 不能同时选
- 包含判据：l ≤ x ≤ r（闭区间，端点值算包含）
- 时限 2000ms，内存 256MB；整体复杂度需 O((n+q) log n) 量级，O(n²) 必超时

## 常见错误

1. **区间调度按左端点（或长度）排序**：贪心选不到"结束最早"的组合，最大不相交数偏小——必须**按右端点 `r` 升序**排序后再扫。
2. **共享端点判成不相交**：写成 `l >= last`，让 [1,2] 与 [2,3] 同时入选——题面规定共享端点即算相交，判据必须是 **`l > last`**。
3. **比较函数写成 `<=`**：`return a.r <= b.r` 违反严格弱序，`sort` 行为未定义（可能死循环或崩）——比较器只用 `<`，相等时落到次级键（如 `a.l < b.l`）。
4. **包含计数逐区间扫描**：每个查询都遍历全部 n 个区间，n·q = 4×10^10 必超时——改成左端点、右端点各排一次序 + 二分，每次查询 O(log n)。
5. **`lower_bound` / `upper_bound` 用混**：数 `l ≤ x` 该用 `upper_bound`（跳过所有 ≤ x 的），数 `r < x` 该用 `lower_bound`（跳过所有 < x 的）——搞反就差一个边界值。
6. **端点值漏算或多算**：x 等于 l 或 r 时按开区间处理，答案少 1——判据是 `l ≤ x ≤ r` 闭区间，二分边界按上面第 5 条对齐。
7. **只输出查询结果忘了第一行**：输出格式是先 1 行最大不相交数、再 q 行查询结果——漏掉第一行或顺序颠倒都会错。
8. **int 存坐标踩边界**：`l`、`r` 最大 10^9，做 `r + 1` 之类的中间运算时 `int` 可能溢出——统一用 `long long` 存坐标和中间量。
