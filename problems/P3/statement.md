# P3 活动安排

## 题目背景

场地本周收到了 n 个活动的预约，第 i 个活动占用半开区间 `[s_i, t_i)`——同一时刻场地只能办一个活动，但一个活动的结束时刻恰好等于另一个的开始时刻时，两场可以连着办。请问最多能安排多少个活动？

## 输入格式

第一行一个整数 `n`，表示活动数量。
接下来 `n` 行，每行两个整数 `s_i` 和 `t_i`，表示第 i 个活动的开始与结束时刻。

## 输出格式

一行一个整数，表示最多能安排的活动数量。

## 样例输入

```
3
1 3
2 5
4 7
```

## 样例输出

```
2
```

## 样例输入 2

```
1
5 10
```

## 样例输出 2

```
1
```

## 样例输入 3

```
4
1 2
2 3
3 4
1 4
```

## 样例输出 3

```
3
```

## 样例输入 4

```
5
1 10
2 3
3 4
4 5
5 6
```

## 样例输出 4

```
4
```

## 样例输入 5

```
4
1 5
2 6
3 7
4 8
```

## 样例输出 5

```
1
```

## 数据范围

- `1 ≤ n ≤ 10^6`
- `0 ≤ s_i < t_i ≤ 10^9`
- **存在隐藏加权用例**：`n = 10^6` 边界的用例权重 ×2，请保证算法复杂度为 `O(n log n)` 或更优。
