# P8 报数出圈

> 难度：基础 · 单文件提交（main.cpp） · 构建：g++ -O2 -std=c++17 · 时限 1000ms / 256MB

## 题目背景

n 个人围成一圈，编号 1..n。从第 s 个人开始报数（s 报 1），报到 m 的人出圈；出圈者的下一个人重新从 1 报数；反复进行，直到所有人都出圈。请输出出圈顺序。

本题考查：输入输出、条件与循环、字符串处理（人名可能带首尾空白，程序必须去除首尾空白）、简单模拟。

## 输入格式

- 第 1 行三个整数 `n s m`，用空格分隔。
- 接下来 n 行，每行一个人名，第 i 行对应编号 i 的人。人名原串长度 1..20，**可能带首尾空格**；去除首尾空白后为非空、内部无空白的字符串。

## 输出格式

n 行，每行一个出圈者的人名（**已去除首尾空白**），按出圈先后顺序输出。


## 提交要求

- 提交**单个源文件** `main.cpp`（C++），由平台执行 `g++ -O2 -std=c++17 -o {bin} {src}` 构建。
- 程序从标准输入读取数据、向标准输出写出结果；调试信息不得写入 stdout，`stderr` 评测忽略。

## 样例输入

```text
5 1 2
 Alice 
Bob
  Carol
Dave 
Eve
```

## 样例输出

```text
Bob
Dave
Alice
Eve
Carol
```

## 样例说明

5 人围圈，编号 1..5 依次是 Alice、Bob、Carol、Dave、Eve（名字里的首尾空格是输入的一部分）。从编号 1 开始报数，报到 2 的人出圈，出圈者的下一个人重新从 1 报数：

1. Alice 报 1，Bob 报 2 → **Bob** 出圈；下一个人 Carol 重新从 1 报。
2. Carol 报 1，Dave 报 2 → **Dave** 出圈；下一个人 Eve 重新从 1 报。
3. Eve 报 1，Alice 报 2 → **Alice** 出圈；下一个人 Carol 重新从 1 报。
4. Carol 报 1，Eve 报 2 → **Eve** 出圈；圈中只剩 Carol。
5. **Carol** 出圈。

出圈顺序：Bob、Dave、Alice、Eve、Carol。输出的每个人名都已去除首尾空白（如 ` Alice ` 输出为 `Alice`）。

## 实现提示

**核心思路**：用**数组模拟环**——维护一个"当前还在圈里的人"的列表，每轮报数到 m 就把对应的人移出并记录，重复直到圈空。n ≤ 1000，O(n²) 的数组搬移模拟即可通过。

**模拟出圈的分步算法（6 步）**：

1. 读入 `n s m` 后，逐行读入 n 个人名；**人名必须用 `getline` 整行读**（`cin >>` 会把行中空白当分隔符读错）；`cin` 读完三个整数后记得吃掉行尾换行（`cin.ignore()`），否则第一条 `getline` 会读到空串；
2. 对每个人名做 **trim（去首尾空白）**：C++ 可手写 while 循环——先从头跳过空格/Tab，再从尾回退跳过空格/Tab，取中间子串（题目保证内部无空白，故 trim 后即为净人名）；
3. 用数组（或 `vector`）存放当前剩余的人，初始为 1..n；另设 `names[i]` 存第 i 个人 trim 后的名字；
4. 每轮**报数定位**：当前剩余 `cnt` 人，从上一轮出圈者的**下一个人**开始数（第一轮从编号 s 开始、s 报 1）。数到第 m 个人出圈——注意 **m 可能大于 cnt**，直接沿圈走 m 步会绕很多圈，应先算 `(m - 1) % cnt` 得到实际要走的步数，再从当前位置前进这么多步（下标记得对 cnt 取模防越界）；
5. 记录出圈者的名字，把它从剩余列表中移除（数组可整体前移或用链表/标记法），`cnt--`；
6. 重复 4~5 直到 `cnt == 0`，按出圈先后输出名字，每人一行。

**关键边界与易错点**：

- **取模位置**：是 `(m - 1) % cnt`（m 报的是"第 m 个"，从 1 开始数，故先减 1），不是 `m % cnt`——`m == cnt` 时应落在最后一个人身上；
- **起点即报数起点**：s 报 1，不是"先跳过 s 个人再从 1 报"；
- **出圈后重新报数**：出圈者的**下一个人**从 1 重新报，不是接着上一轮的报数继续数；
- **人名空白**：` Alice ` 输出必须是 `Alice`——存之前就 trim 好，别输出时再处理；用 `getline` 读入的串会自带行尾可能的 `\r`，也要一并清掉；
- **单人边界**：n = 1 时直接出圈；`cnt == 1` 时 `(m - 1) % 1 == 0`，不会除零，但循环里别让 `cnt` 减到 0 后再取模。

## 数据范围

- 1 ≤ n ≤ 1000
- 1 ≤ s ≤ n
- 1 ≤ m ≤ 1000
- 人名原串长度 1..20；去首尾空白后非空、内部无空白
- 时限 1000ms，内存 256MB

## 常见错误

1. **用 `cin >>` 读人名**：人名带首尾空格时 `cin >>` 会跳过前导空白、把名字读残或串行——改用 `getline` 整行读，且 `cin` 读完 `n s m` 后 `cin.ignore()` 吃掉行尾换行。
2. **忘了去首尾空白**：直接输出原串，` Alice ` 印成 ` Alice `，行末/行首多空格被判格式错误——读入后立即手写 while 循环 trim 前后空白再存储。
3. **报数不取模**：m 大于剩余人数时硬走 m 步绕圈数错位置——每轮先算 `(m - 1) % cnt` 折算实际步数再走。
4. **起点处理错**：把 s 当成"先跳过 s 个人再报 1"——题面规定 s 本人就报 1，第一轮直接从 s 开始数。
5. **出圈后报数没重置**：接着上一轮报到的数字继续数——出圈者的下一个人必须**重新从 1** 报。
6. **剩余人数不减或减早了**：出圈后没 `cnt--`，下一轮取模分母偏大，数到已出圈的人——出圈即减，且取模用最新的 cnt。
7. **`cnt` 减到 0 后仍取模**：最后一轮 `cnt == 0` 时 `% 0` 是未定义行为——循环条件先判 `cnt > 0`，取模只在还有人时做。
8. **名字数组越界**：环形前进时下标没对 `cnt` 取模，走到数组末尾之后——每次前进后 `pos %= cnt`（或等价的取模写法）。
