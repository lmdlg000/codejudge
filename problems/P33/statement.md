# P33 韩信点兵

> 难度：中等 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB

> 题源：情境拓展 ·《趣味数学及编程拓展》4.1 韩信点兵。本题题面自包含，无需查阅原卷。

## 题目背景

相传韩信点兵时，让士兵三人一组、五人一组、七人一组报数，只记每组余下的人数，就能推算出总人数。这就是著名的「中国剩余定理」雏形。已知某数分别除以 3、5、7 的余数，请反推出满足条件的最小正整数。

## 输入格式

一行，三个整数 a b c，分别表示除以 3、5、7 的余数。

## 输出格式

一行，一个整数，表示满足条件的最小正整数。

## 样例输入

```
2 3 2
```

## 样例输出

```
23
```

## 样例输入 2

```
0 0 0
```

## 样例输出 2

```
105
```

## 数据范围

- 0 ≤ a < 3，0 ≤ b < 5，0 ≤ c < 7
- 判题采用 trim 比对：忽略行末与整体首尾空白，行内空格敏感。

## 思路提示

三个模数 3、5、7 两两互质，最小公倍数为 105，因此解在 1..105 内唯一存在，直接从小到大枚举即可。也可用中国剩余定理公式一次算出。

## 常见错误

1. 求的是最小正整数，不能输出 0（除非输入全 0 时解为 105，本题按 x=1..105 枚举得 105）
2. 余数可能为 0
3. 注意 a,b,c 的取值范围
