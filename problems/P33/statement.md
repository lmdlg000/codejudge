# P33 哥德巴赫配对

> 难度：中等 · 计分：ACM · **C++ 语言题**，单文件提交（main.cpp） · 构建：g++ -O2 -std=c++17 · 时限 2000ms / 256MB

> 题源：情境拓展 ·《趣味数学及编程拓展》2.6.1 哥德巴赫猜想。本题题面自包含，无需查阅原卷。

## 题目背景

哥德巴赫猜想指出：任何大于 2 的偶数都可以写成两个素数之和。虽然猜想本身至今未被完全证明，但小范围内总能找到这样的素数对。给定一个偶数，请找出一对和为它的素数，并要求其中较小的那个素数尽可能小。

## 输入格式

一行，一个偶数 n（4 ≤ n ≤ 200000）。

## 输出格式

一行，两个素数 p 和 q（p ≤ q 且 p + q = n），p 取所有可行解中最小者，两数间一个空格；若无解输出 NO。

## 样例输入

```
10
```

## 样例输出

```
3 7
```

## 样例输入 2

```
4
```

## 样例输出 2

```
2 2
```

## 样例输入 3

```
8
```

## 样例输出 3

```
3 5
```

## 数据范围

- 4 ≤ n ≤ 200000，且 n 为偶数
- 判题采用 trim 比对：忽略行末与整体首尾空白，行内空格敏感。

## 思路提示

先用埃氏筛求出 [2,n] 的素数表，再从 p=2 向 n/2 枚举，第一个满足 p 与 n-p 都是素数的 p 就是最小解。注意 n 为偶数，n-p 也为偶数时只有 p=2,n-p=2 一种特殊情况。

## 常见错误

1. 筛法从 i*i 开始标记，避免重复
2. 必须 p<=q（枚举到 n/2 即可）
3. 无解输出大写 NO
