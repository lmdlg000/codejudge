# P37 螺旋方阵

> 难度：中等 · 计分：OI · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB

> 题源：情境拓展 ·《趣味数学及编程拓展》第 8 章 数形结合（螺旋填数）。本题题面自包含，无需查阅原卷。

## 题目背景

把 1 到 n² 依次填入 n 阶方阵，从左上角开始先向右、再向下、再向左、再向上，逐圈向内收缩，就得到一个螺旋方阵。这类填数问题考察对二维数组边界的精确控制。

## 输入格式

一行，一个整数 n（1 ≤ n ≤ 20）。

## 输出格式

输出 n 行，每行 n 个整数（1..n² 各出现一次），同一行相邻整数间用一个空格分隔，行末不留多余空格。

## 样例输入

```
4
```

## 样例输出

```
1 2 3 4
12 13 14 5
11 16 15 6
10 9 8 7
```

## 样例输入 2

```
3
```

## 样例输出 2

```
1 2 3
8 9 4
7 6 5
```

## 数据范围

- 1 ≤ n ≤ 20
- 判题采用 trim 比对：忽略行末与整体首尾空白，行内空格敏感。

## 思路提示

用 top/bottom/left/right 四个边界表示尚未填充的矩形区域，每填完一条边就收缩对应边界，并在收缩后检查是否交叉，避免中心行/列被重复填。

## 常见错误

1. n=1 时只填一个 1
2. 奇数阶最后剩中心格，不能在收缩后重复填
3. 行内元素间恰好一个空格
