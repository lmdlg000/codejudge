# P23 数组极差

> 难度：简单 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：C 语言题库 2021 编程题改编。本题题面自包含，无需查阅原卷。

## 题目背景

极差是一组数据中最大值与最小值之差，用来粗略衡量数据的波动幅度，例如一天内气温的变化范围。

给定 n 个整数，请输出它们的极差。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 1000）。
第二行 n 个整数，用空格分隔。

## 输出格式

一行，一个整数，即最大值减去最小值的结果。

## 样例输入

```
6
1 3 5 10 7 4
```

## 样例输出

```
9
```

样例说明：最大值 10、最小值 1，极差 = 10 - 1 = 9。

## 样例输入 2

```
4
-2 -8 0 5
```

## 样例输出 2

```
13
```

样例说明：最大值 5、最小值 -8，极差 = 5 - (-8) = 13。

## 数据范围

- 1 ≤ n ≤ 1000
- 每个整数在 32 位有符号整数范围内

## 思路提示

读入第一个数，同时把它作为最大值和最小值的初值；之后每读入一个数，分别更新最大值和最小值；最后输出两者之差。极差永远非负。

## 常见错误

1. 最大值和最小值用了不同的初值（如 0 和 10000），遇到相反符号的数据会算错。
2. 只遍历了一次却漏掉第一个元素。
3. n = 1 时极差应为 0，不要输出其他值。
