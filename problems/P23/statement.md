# P23 日期比较

> 难度：中等 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：C 语言题库 2022 秋程序设计题改编。本题题面自包含，无需查阅原卷。

## 题目背景

在日程安排、日志排序等场景中，经常需要比较两个日期的先后。

给定两个日期（年、月、日），请判断它们的先后关系。

## 输入格式

第一行三个整数 y1 m1 d1，表示第一个日期。
第二行三个整数 y2 m2 d2，表示第二个日期。
输入保证两个日期都是合法日期。

## 输出格式

一行，一个整数：

- 若日期 1 早于日期 2，输出 1；
- 若两个日期完全相同，输出 0；
- 若日期 1 晚于日期 2，输出 -1。

## 样例输入

```
2023 12 15
2021 4 8
```

## 样例输出

```
-1
```

样例说明：2023 年晚于 2021 年，故日期 1 更晚，输出 -1。

## 样例输入 2

```
2020 1 1
2020 1 1
```

## 样例输出 2

```
0
```

## 样例输入 3

```
1999 12 31
2000 1 1
```

## 样例输出 3

```
1
```

## 数据范围

- 1 ≤ y ≤ 9999，1 ≤ m ≤ 12，1 ≤ d ≤ 31
- 输入保证日期合法（包括闰年的 2 月 29 日）

## 思路提示

按年、月、日的顺序逐级比较：年份不同直接按大小返回；年份相同看月份；月份也相同再看日；全部相等返回 0。不需要把日期换算成天数，也不需要校验合法性。

## 常见错误

1. 把"早"和"晚"的返回值弄反——本题是早返回 1、晚返回 -1。
2. 只比较年份或只比较月份，漏掉更细的粒度。
3. 把两个日期(year,month,day)拼成整数相减后再判断符号，容易因位数不齐出错。
