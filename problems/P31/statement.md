# P31 卡普雷卡尔操作

> 难度：中等 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：情境拓展 ·《趣味数学及编程拓展》3.9.1 卡普雷卡尔操作。本题题面自包含，无需查阅原卷。

## 题目背景

6174 是四位数的"数字黑洞"。对任意一个各位数字不全相同的四位数，重复如下操作，最终一定会收敛到 6174：

1. 把这个数的 4 位数字从大到小排列，组成最大数；
2. 把同样的数字从小到大排列，组成最小数（不足 4 位时高位补 0）；
3. 用最大数减去最小数，得到一个新数，继续下一轮。

例如 3524：5432 - 2345 = 3087；8730 - 378 = 8352；8532 - 2358 = 6174，共 3 步。

给定初始数，请输出到达 6174 所需的操作次数。

## 输入格式

一行，一个四位数 n（1000 ≤ n ≤ 9999），保证各位数字不全相同。

## 输出格式

一行，一个整数，表示到达 6174 的操作次数；若输入本身就是 6174，输出 0。

## 样例输入

```
3524
```

## 样例输出

```
3
```

## 样例输入 2

```
6174
```

## 样例输出 2

```
0
```

## 样例输入 3

```
1234
```

## 样例输出 3

```
3
```

## 数据范围

- 1000 ≤ n ≤ 9999，各位数字不全相同

## 思路提示

每轮取 n 的 4 位数字存入数组（用 `d[i] = n % 10; n /= 10;`），排序后从大到小拼出 desc、从小到大拼出 asc，令 n = desc - asc 并计步。差可能不足四位（如 999），拼 desc 时 4 位都要参与，高位自然为 0，这正是"补 0 再排"的效果。

## 常见错误

1. 差不足四位时只按实际位数排序（把 999 排成 999 而不是 0999），结果会错。
2. 输入本身是 6174 时仍执行一轮，输出 1 而不是 0。
3. 循环没有终止条件，无限执行。
