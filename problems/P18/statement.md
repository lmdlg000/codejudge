# P18 素数因子分解

> 难度：简单 · 计分：ACM · **C++ 语言题**，单文件提交（main.cpp） · 构建：g++ -O2 -std=c++17 · 时限 1000ms / 256MB
> 题源：C++ 历年试卷编程题改编。本题题面自包含，无需查阅原卷。

## 题目背景

根据算术基本定理，任何大于 1 的整数都能唯一地分解成若干个素数的乘积。例如 2310 = 2 × 3 × 5 × 7 × 11。

给定一个整数 n，请找出它的所有**不同**素数因子（每个因子只输出一次，不输出重数），按从小到大的顺序输出。例如 16 = 2⁴，只输出一个 2。

## 输入格式

一行，一个整数 n（2 ≤ n ≤ 10⁹）。

## 输出格式

一行，将所有不同的素数因子按从小到大输出，用**单个空格**分隔，行末不留多余空格。如果 n 本身是素数，则输出 n 本身。

## 样例输入

```
2310
```

## 样例输出

```
2 3 5 7 11
```

## 样例输入 2

```
7
```

## 样例输出 2

```
7
```

## 样例输入 3

```
16
```

## 样例输出 3

```
2
```

样例说明：2310 = 2×3×5×7×11；7 本身是素数，输出 7；16 = 2×2×2×2，不同的素因子只有 2。

## 数据范围

- 2 ≤ n ≤ 10⁹

## 思路提示

从 d = 2 开始试除。若 n % d == 0，则 d 是一个素因子，输出它，并用一个循环把 n 中所有的 d 因子除尽（写 `while (n % d == 0) n /= d;`），这样既能去重，也能保证后面找到的仍然是素数。循环条件写成 `d * d <= n`：当 d 超过 √n 后，若剩余的 n > 1，则它本身就是一个素数，需要单独输出。d 建议用 long long，避免 `d * d` 溢出。

## 常见错误

1. 忘记除尽同一个因子，16 会输出成 `2 2 2 2`。
2. 循环条件写成 `d <= n`，输入大质数时超时。
3. 循环结束漏掉剩余的 `n > 1`，7、97 这类质数会输出空行。
