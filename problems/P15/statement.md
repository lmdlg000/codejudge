# P15 成绩单排版

> 难度：简单 · **C 语言题**，单文件提交（main.c） · 构建：`gcc -O2 -std=c11` · 时限 1000ms / 256MB

## 题目背景

教务系统导出的成绩是一堆用空格隔开的数据，打印出来却要**按列对齐**：学号、姓名、三科成绩、平均分各占固定宽度，小数点也要对齐到同一位。用 `printf` 的宽度与精度控制一行就能排好，用「拼空格」的写法则会在姓名长短不一的时候全线崩掉。

请读入一个班的成绩，输出排版好的成绩单，并在末尾给出及格情况与班级平均分。

本题考查：格式化输出（宽度、左/右对齐、小数位、`%%` 转义）、字符串读入、数组与循环、简单统计。

## 输入格式

- 第 1 行一个整数 `n`（1 ≤ n ≤ 200）。
- 接下来 n 行，每行 `id name c1 c2 c3`，用一个或多个空格分隔：
  - `id` 是**恰好 8 位**的数字串；
  - `name` 是不含空格的字符串，长度 1..10；
  - `c1 c2 c3` 是三科成绩，均为 0..100 的整数。

## 输出格式

输出一张表，按下面的**五段**顺序：

1. **表头行**：六列，列名依次是 `ID`、`NAME`、`C1`、`C2`、`C3`、`AVG`；
2. **分隔线**：42 个半角减号 `-`；
3. **数据行**：每个学生一行，列顺序与表头一致；
4. **分隔线**：再一行 42 个 `-`；
5. **统计两行**：
   - `PASS p/n (xx.x%)`：p 为及格人数（三科平均 ≥ 60 即及格），百分比为 `p/n*100`；
   - `CLASS AVG yy.yy`：全班所有学生平均分的平均值。

**列宽与对齐**（列与列之间正好**一个空格**，不要再加别的空格）：

| 列 | 宽度 | 对齐 | 内容 |
|---|---|---|---|
| ID | 8 | 左对齐，不足补空格 | 学号（正好 8 位，不会补） |
| NAME | 10 | 左对齐，不足补空格 | 姓名 |
| C1 | 4 | 右对齐，不足补空格 | 第一科成绩 |
| C2 | 4 | 右对齐 | 第二科成绩 |
| C3 | 4 | 右对齐 | 第三科成绩 |
| AVG | 7 | 右对齐 | 平均分，**保留 2 位小数** |

- 平均分 = `(c1+c2+c3)/3.0`（实数除法，不要取整）。
- 及格判定用**未取整**的平均分与 60 比较：`59 60 61` 的平均分正好 60，算及格。
- 百分比保留 **1 位小数**，后面跟一个百分号。

## 提交要求

- 提交**单个源文件** `main.c`，由平台执行 `gcc -O2 -std=c11 -o {bin} {src}` 构建（**按 C11 编译，不是 C++**）。
- 只能用 C 标准库（`stdio.h` / `string.h` / `math.h` …）：`scanf`/`printf`/`gets` 那一套。**不要**出现 `#include <iostream>`、`cout`、`string`、`vector`、`class` —— 用 C++ 写法提交会直接编译失败。
- `gets()` 在 C11 里已经被移除，读整行请用 `fgets`。
- 只从标准输入读、只往标准输出写；调试信息不得写入 stdout。

## 样例说明

- **样例 1**：Alice 的平均分是 (95+100+88)/3 = 94.333…，输出 `94.33`（两位小数四舍五入）；Bob 55.00 不及格，ChenLong 83.67 及格，所以是 `PASS 2/3`，百分比 2/3×100 = 66.66…% 取 1 位小数得 `66.7%`。班级平均 = (94.33…+55+83.66…)/3 = 77.66… → `77.67`。
- **样例 2**：姓名 `WangXiaoyu` 正好 10 个字符，NAME 列不需要补空格，所以它后面紧跟分隔用的那一个空格。姓名短的时候（如 `H`）要补 9 个空格。
- **样例 3**：两人都不及格 → `0/2 (0.0%)`。注意 `0.0` 这一位也要照实输出，不能只写 `0%`。
- **样例 4**：`59+60+61 = 180`，平均分正好 60.00，**算及格**——不要写成 `> 60`。
- **样例 5**：数据全为整数分、平均分也是整数时，仍要输出两位小数（`91.00` 而不是 `91`）。

## 实现提示

**一行 `printf` 就能排完整行**，格式串里每个 `%` 转换说明直接对应一列：

- `%-8s`：字符串占 8 列、左对齐、不够用空格补在右边；
- `%4d`：整数占 4 列、右对齐（`%4d` 默认右对齐，想左对齐要写 `%-4d`）；
- `%7.2f`：实数占 7 列、保留 2 位小数；
- `%%`：输出一个百分号本身（单独的 `%` 是格式符的引导字符，必须写两遍）。

**分步算法（4 步）**：

1. 读 `n`；
2. 先输出表头行与第一行分隔线；
3. 循环 n 次：读 `id name c1 c2 c3`，算 `avg = (c1+c2+c3)/3.0`，按同一套列宽输出一行，同时累计及格人数与平均分之和；
4. 输出第二条分隔线、`PASS p/n (xx.x%)`、`CLASS AVG yy.yy`。

**关键边界与易错点**：

- **表头也要用同一套列宽**：表头的 `ID`、`NAME` 是字符串，用 `%-8s`、`%-10s`；`C1`、`C2`、`C3`、`AVG` 也是字符串，同样占 4 / 4 / 4 / 7 列（写成 `%4s`、`%7s`），这样表头和数据才能在竖直方向对齐。
- **列之间只有一个空格**，宽度本身已经负责补位，别再手工加一串空格。
- **平均分用浮点算**：`(c1+c2+c3)/3` 是整数除法，`59 60 61` 会先算成 60 再比较——看起来没错，但 `59 60 59` 会被截成 59 从而判错档。统一写 `/ 3.0`。
- **百分比要转义**：`printf("%.1f%%", pct)`，漏掉一个 `%` 会输出乱码甚至崩溃。
- **姓名不含空格**，所以 `scanf("%s")` 就够；不要用 `gets`（C11 起已从标准库删除，本项目按 C++17 编译会直接编译失败），需要读整行请用 `fgets`。

## 数据范围

- 1 ≤ n ≤ 200
- 学号恰好 8 位数字；姓名 1..10 个字符，不含空白
- 0 ≤ c1, c2, c3 ≤ 100

## 常见错误

1. **用 `%s` 输出姓名不设宽度**：`Alice` 和 `WangXiaoyu` 后面的列会错开，整张表歪掉。
2. **表头直接写成一整个字符串**：手打的空格数一旦和各列宽度对不上，看起来只差一格，判题直接 WA。
3. **整数除法**：`avg = (c1+c2+c3)/3;` 丢掉小数，`94.33` 变成 `94.00`。
4. **`%.2f` 忘了宽度**：`94.33` 和 `100.00` 宽度不同，AVG 列右端参差不齐。
5. **百分号没转义**：`printf("%.1f%", x)` 会把 `%` 后面的字符当格式符，输出乱码甚至崩溃。
6. **及格判断用 `> 60`**：正好 60 分的人被算成不及格。
7. **分隔线数量数错**：写死成 40 或 44 个减号，与表头不等宽。
8. **交成 C++**：文件里出现 `cout` / `string` / `#include <iostream>`，`gcc` 按 C11 编译直接报错。
