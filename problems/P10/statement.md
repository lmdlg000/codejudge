# P10 最短路计数

> 难度：提高 · 多文件 make 工程（恰好 6 个文件） · 构建：`make` → `router` · 时限 2000ms / 256MB

## 题目背景

给定 n 个结点的有向带权图（结点编号 1..n，边权 w ≥ 0，**无重边、无自环**）。求从结点 1 到结点 n 的：

1. **最短路长度 D**；
2. **最短路的条数**（对 1000000007 取模）。

两条路径不同 ⟺ **边序列不同**（走过相同边序列视为同一条路径；允许经过重复结点，只要边序列不同就算不同路径）。题目保证最短路条数有限（即不存在全部位于最短路上的 0 权环）。

注意边权可以为 **0**：0 权边会制造大量**等长**的最短路，计数必须把它们全部算上，并按拓扑次序在最短路 DAG 上递推——同 dist 层内若不按拓扑序推进会漏算。

- 若 1 不可达 n：输出 `-1 0`；
- 若 n = 1：输出 `0 1`（起点即终点，长度为 0 的平凡路径恰 1 条）。

n、m 最大 10 万、20 万，O(n·m) 的 Bellman-Ford 式迭代或 O(n²) 的朴素 Dijkstra 必超时，需要堆优化 Dijkstra + 最短路 DAG 上的 DP，整体 O(m log n) 量级。

本题考查：图论（Dijkstra 最短路）、最短路 DAG 上的动态规划计数、0 权边边界处理、取模运算、多文件工程组织（模块拆分 + makefile）。

## 输入格式

- 第 1 行两个整数 `n m`。
- 接下来 m 行，每行三个整数 `u v w`，表示一条 u → v、边权为 w 的有向边（无重边、无自环）。

## 输出格式

- 一行两个整数 `D cnt`：D 是 1 到 n 的最短路长度，cnt 是最短路条数对 1000000007 取模的结果。
- 1 不可达 n 时输出 `-1 0`；n = 1 时输出 `0 1`。


## 提交要求（多文件 make 工程）

多文件提交**恰好包含这 6 个文件**（文件名固定）：

| 文件 | 内容 |
| --- | --- |
| `graph.h` / `graph.C` | 建图 + Dijkstra 最短路模块 |
| `paths.h` / `paths.C` | 最短路 DAG 上 DP 计数模块 |
| `main.C` | 主程序：读入、调用两个模块、按格式输出 |
| `makefile` | 构建规则（见下） |

- **`.h` 只放声明 + 头文件保护宏**（`#ifndef/#define/#endif`），实现全部放 `.C`；
- 每个 `.C` **首行 `#include` 对应的 `.h`**（如 `graph.C` 首行 `#include "graph.h"`）；
- 允许使用 STL 容器与 `<queue>`、`<algorithm>` 等（本题考算法组织而非裸字符处理）；
- `makefile` 要求：`TARGET = router`、`all` 生成 `router`、`clean` 删除 `.o` 与 `router`、`CXX = g++`、`CXXFLAGS = -std=c++20 -O2 -w -Wall`、每个 `.o` 写清依赖的 `.h`、**配方行以 Tab 缩进**（不是空格）、**不写死绝对路径**。参考模板（`$(CXX)`、`rm` 行前是 Tab）：

```makefile
CXX = g++
CXXFLAGS = -std=c++20 -O2 -w -Wall
OBJ = main.o graph.o paths.o
TARGET = router

all: $(TARGET)

$(TARGET): $(OBJ)
	$(CXX) $(CXXFLAGS) -o $(TARGET) $(OBJ)

main.o: main.C graph.h paths.h
	$(CXX) $(CXXFLAGS) -c main.C

graph.o: graph.C graph.h
	$(CXX) $(CXXFLAGS) -c graph.C

paths.o: paths.C paths.h graph.h
	$(CXX) $(CXXFLAGS) -c paths.C

clean:
	rm -f $(OBJ) $(TARGET)

.PHONY: all clean
```

变量名与 `.o` 列表可自行调整，但行为必须满足：`make` 生成 `router`、`make clean` 清干净 `.o` 与可执行文件、每个 `.o` 依赖写全对应的 `.h`。

## 样例输入

```text
4 5
1 2 2
2 4 2
1 3 1
3 4 3
1 4 10
```

## 样例输出

```text
4 2
```

## 样例说明

4 个结点 5 条边：

- 1→2→4 长度 2+2 = **4**；
- 1→3→4 长度 1+3 = **4**；
- 1→4 直达长度 10。

最短路长度 **D = 4**，等长最短路共 **2** 条（边序列分别为 (1→2, 2→4) 与 (1→3, 3→4)），故输出 `4 2`。

## 实现提示

本题是"**单源最短路 + 最短路 DAG 上的 DP 计数**"两步走，正好对应 `graph.*`（求 dist）与 `paths.*`（数路径）两个模块。

**第一步：堆优化 Dijkstra 求 `dist[]`（6 步）**

1. 用**邻接表**存图（`vector<vector<pair<int,long long>>>`，pair 存 (邻居, 边权)）；
2. `dist[]` 全部初始化为 **INF**（`long long` 的大数，如 `4e18`），`dist[1] = 0`；
3. 用**最小堆**（`priority_queue` 取 dist 最小的结点）维护待扩展结点；
4. 每次弹出堆顶 `(d, u)`：若 `d > dist[u]` 则是过期条目直接跳过（**懒删除**）；
5. 松弛所有出边 `u → v`（边权 `w`）：若 `dist[u] + w < dist[v]`，更新 `dist[v]` 并把新条目压堆；
6. 堆空后 `dist[]` 即为最短路长度；若 `dist[n]` 仍为 INF，输出 `-1 0` 直接结束（n = 1 特判：输出 `0 1`）。

**第二步：最短路 DAG 上 DP 计数（5 步）**

7. **筛边建 DAG**：遍历所有边 `u → v`（边权 `w`），只保留满足 **`dist[v] == dist[u] + w`** 的边——这些边恰好组成所有最短路的并集（最短路 DAG）；其余边不可能出现在任何最短路上，直接丢弃；
8. **按 dist 值分层**：把结点按 `dist` 从小到大排序（或用桶/`map` 分层），得到 DAG 的**拓扑序**——DAG 上任何边 `u → v` 都满足 `dist[u] ≤ dist[v]`，故按 dist 升序处理即合法拓扑序；
9. 初始化 `cnt[1] = 1`、其余 `cnt[] = 0`；
10. 按拓扑序扫描每个结点 `u`，沿 DAG 出边 `u → v` 转移：**`cnt[v] = (cnt[v] + cnt[u]) % MOD`**（MOD = 1000000007）——这就是"`cnt[v] = Σ cnt[u]`（对所有入边）"的逐边松弛写法，效果等价；
11. 答案为 `dist[n]` 与 `cnt[n]`（若 `dist[n]` 为 INF 则 `0`）。

**0 权边的处理（本题最易错）**：

- 权为 0 的边会让**不同结点的 dist 相等**（`dist[v] == dist[u] + 0`），即存在"同层"的 DAG 边；
- 按 dist 分层时，**同一层内的结点也必须按拓扑序推进**：若同一 dist 值的多个结点之间有 0 权边，随便按编号顺序转移会漏算/重算——正确做法是把 (dist, 编号) 一起排序，或对同层结点再做一次**同层拓扑排序**（按层内入度推进），保证边 `u → v` 处理时 `u` 的计数已经定型；
- 最稳的写法：把 DAG 的所有结点按 `dist` 为第一关键字升序、编号为第二关键字排序后依次松弛；若同层内有 0 权边，再对同层子图单独按入度拓扑推进一遍（题目保证无全 0 权环，故同层拓扑必存在）。

**关键边界与易错点**：

- **dist 用 `long long`**：单条边权最大 10^9，路径最多 n−1 条边，`int` 存 dist 会溢出（最大约 10^14）；
- **每一步取模**：计数累加时 `cnt[v] = (cnt[v] + cnt[u]) % MOD`，只在最后取模一样会溢出 `long long`（路径条数指数级增长）；
- **n = 1 与不可达的特判**：`n == 1` 输出 `0 1`（长度 0 的平凡路径恰 1 条）；`dist[n] == INF` 输出 `-1 0`，**不要**输出 `INF` 或漏掉 0；
- **Dijkstra 的懒删除**：堆里同一结点可能有多条过期条目，弹出时必须判 `d > dist[u]` 跳过，否则复杂度退化甚至结果错。

## 数据范围

- 1 ≤ n ≤ 100000，0 ≤ m ≤ 200000
- 1 ≤ u, v ≤ n，u ≠ v；无重边、无自环
- 0 ≤ w ≤ 10^9
- 最短路条数对 **1000000007** 取模
- 保证不存在全部位于最短路上的 0 权环（最短路条数有限）
- 时限 2000ms，内存 256MB；整体复杂度需 O(m log n) 量级，O(n·m) 或 O(n²) 必超时

## 常见错误

1. **忘记取模**：路径条数只在最后对 1000000007 取一次模——条数指数级增长，中途 `long long` 早就溢出；每次累加 `cnt[v] = (cnt[v] + cnt[u]) % MOD`。
2. **用 `int` 存 dist**：边权 w 最大 10^9、路径最多 n−1 条边，dist 可达 10^14 量级——`int` 溢出后松弛判断全错，dist 数组必须用 `long long`。
3. **0 权边漏算**：建 DAG 时只保留 `w > 0` 的边、或分层后同层结点不按拓扑序推进——`dist[v] == dist[u] + 0` 的边也是最短路边，同层内必须按拓扑序（或 (dist, 编号) 排序 + 同层入度推进）转移。
4. **DAG 边筛错**：把判据写成 `dist[v] > dist[u]` 或 `dist[v] >= dist[u] + w`，混进非最短路边——精确判据是 **`dist[v] == dist[u] + w`**。
5. **计数起点不对**：`cnt[1]` 没初始化成 1（或 n = 1 时忘了 `0 1` 的特判）——`cnt[1] = 1` 是 DP 初值，n = 1 直接输出 `0 1`。
6. **不可达输出格式错**：`dist[n] == INF` 时输出 `INF 0`、`-1 1` 或漏了计数——必须恰好是 **`-1 0`**。
7. **Dijkstra 不做懒删除**：堆里的过期条目不判 `d > dist[u]` 就松弛——结果可能错、复杂度退化到 O(m²)；弹出时先比 dist 再决定要不要扩展。
8. **用普通队列/不带堆的 Dijkstra**：O(n²) 朴素 Dijkstra 或 O(n·m) 的 Bellman-Ford 在 n=10^5 下必超时——用 `priority_queue` 堆优化，整体 O(m log n)。
