# P2 字符串压缩

## 题目背景

日志系统里存着大量只含小写字母的字符串，很多字符连续重复。为了节省空间，需要把每个连续相同字符段压缩成「字符 + 段长」的形式。例如 `aaabbc` 压缩为 `a3b2c1`。段长为 1 时也要写上数字，保证输出格式唯一。

## 输入格式

一行一个只含小写字母的字符串 `s`。

## 输出格式

一行一个字符串，表示压缩结果：按从左到右的顺序，对每个连续相同字符段输出「字符 + 该段长度」。

## 样例输入

```
aaabbc
```

## 样例输出

```
a3b2c1
```

## 样例输入 2

```
a
```

## 样例输出 2

```
a1
```

## 样例输入 3

```
zzzzzzzzzz
```

## 样例输出 3

```
z10
```

## 样例输入 4

```
abcabc
```

## 样例输出 4

```
a1b1c1a1b1c1
```

## 样例输入 5

```
aabbaa
```

## 样例输出 5

```
a2b2a2
```

## 数据范围

- `1 ≤ |s| ≤ 100000`
- `s` 仅由小写字母 `a`–`z` 组成。
