# P27 回文素数

> 难度：中等 · 计分：OI · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：情境拓展 ·《趣味数学及编程拓展》2.3 对称素数。本题题面自包含，无需查阅原卷。

## 题目背景

回文数是从左读和从右读都一样的数，如 121、131。素数则是大于 1 且只能被 1 和自身整除的数。同时满足两者的数称为对称素数（回文素数），例如 2、3、5、7、11、101。

给定区间 [a, b]，请输出其中所有的回文素数。

## 输入格式

一行，两个整数 a 和 b（1 ≤ a ≤ b ≤ 10000）。

## 输出格式

一行，把区间 [a, b] 内所有回文素数按从小到大输出，用单个空格分隔；若一个都没有，输出一个空行。

## 样例输入

```
1 200
```

## 样例输出

```
2 3 5 7 11 101 131 151 181 191
```

## 样例输入 2

```
1 100
```

## 样例输出 2

```
2 3 5 7 11
```

## 数据范围

- 1 ≤ a ≤ b ≤ 10000

## 思路提示

对区间内每个数 n 依次做两次判定：`isPrime(n)` 用试除到 d*d ≤ n；`isPalin(n)` 用 sprintf 转成字符串后双指针从两端向中间比较。两个条件都满足才输出。用 first 标志控制空格。

## 常见错误

1. 把 1 当成素数——1 不是素数。
2. 回文判断只比较了一半就提前返回 true。
3. 输出时用逗号分隔而不是题目要求的空格。
4. 区间无解时没有输出空行。
