# P27 水仙花数

> 难度：简单 · 计分：OI · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB
> 题源：情境拓展 ·《趣味数学及编程拓展》1.1.1 水仙花数。本题题面自包含，无需查阅原卷。

## 题目背景

"水仙花数"是一类有趣的三位数：它恰好等于自己各位数字的立方和。例如 153 = 1³ + 5³ + 3³ = 1 + 125 + 27。三位水仙花数总共只有 4 个。

给定区间 [a, b]，请输出其中所有的三位水仙花数。

## 输入格式

一行，两个整数 a 和 b（1 ≤ a ≤ b ≤ 100000）。

## 输出格式

一行，把区间 [a, b] 内所有三位水仙花数按从小到大输出，用单个空格分隔；若一个都没有，输出一个空行。

## 样例输入

```
100 999
```

## 样例输出

```
153 370 371 407
```

样例说明：153 = 1³+5³+3³，370 = 3³+7³+0³，371 = 3³+7³+1³，407 = 4³+0³+7³。

## 样例输入 2

```
100 200
```

## 样例输出 2

```
153
```

## 数据范围

- 1 ≤ a ≤ b ≤ 100000
- 水仙花数按"三位数"定义（100 ≤ n ≤ 999），区间超出三位的部分不产生解

## 思路提示

枚举 n 从 max(a, 100) 到 min(b, 999)，对每个 n 用 `x = n; while (x) { d = x % 10; s += d*d*d; x /= 10; }` 求立方和，相等则输出。用 first 标志控制空格，避免行首或行尾出现多余空格。

## 常见错误

1. 把超出 999 的数也拿来判定——三位水仙花数只对三位数定义。
2. 区间无解时没有任何输出，忘记输出空行。
3. 分离数字时以为 0 可以忽略——如 407 中间的 0 必须参与（虽然对立方和无贡献）。
