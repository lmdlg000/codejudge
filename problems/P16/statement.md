# P16 机柜状态

> 难度：中等 · **C 语言题**，单文件提交（main.c） · 构建：`gcc -O2 -std=c11` · 时限 2000ms / 256MB

## 题目背景

机柜上有一排指示灯，每个机柜用**一个 32 位无符号整数**记录整排灯的状态：第 `b` 位为 1 表示第 b 盏灯亮着（b 从 0 数到 31）。

运维脚本按顺序下发指令修改状态，改完之后再按区间统计"亮灯总数"。请写程序把这批指令和查询都执行掉。

指令共四种：

| 指令 | 格式 | 含义 |
|---|---|---|
| 置位 | `S i b` | 把第 i 个机柜的第 b 位置为 1 |
| 清位 | `C i b` | 把第 i 个机柜的第 b 位置为 0（本来就是 0 也不报错） |
| 翻转 | `F i b` | 把第 i 个机柜的第 b 位取反 |
| 交换 | `W i` | 把第 i 个机柜状态字的**高 16 位与低 16 位互换** |

查询 `l r`：求第 l 到第 r 个机柜（含两端）**亮灯数之和**，也就是这些状态字里二进制 1 的个数总和。

本题考查：位运算（置 1 / 清 0 / 取反 / 移位与拼接）、`scanf("%x")` 读十六进制、二进制中 1 的个数统计、前缀和把区间查询降到 O(1)、多组数据读到 EOF。

## 输入格式

输入包含**若干组**数据，读到文件结束（EOF）为止。每组：

- 第 1 行三个整数 `n m q`：机柜个数、指令条数、查询个数。
- 接下来 n 行，每行一个十六进制状态字，形如 `0x00FF00FF`（带 `0x` 前缀，共 8 位十六进制数字）。
- 接下来 m 行，每行一条指令：`S i b`、`C i b`、`F i b` 或 `W i`。
- 接下来 q 行，每行两个整数 `l r`。

所有指令都在所有查询**之前**执行完毕。

## 输出格式

按顺序输出每组数据的查询结果，每个查询一行一个整数。

## 提交要求

- 提交**单个源文件** `main.c`，由平台执行 `gcc -O2 -std=c11 -o {bin} {src}` 构建（**按 C11 编译，不是 C++**）。
- 只能用 C 标准库（`stdio.h` / `string.h` …），**不要**用 `#include <iostream>`、`cout`、`vector`、`class`。
- 无符号运算请用 `unsigned int` 与 `1u << b`；`__builtin_popcount` 是 GCC 内建函数，可以用，但手写循环同样能过。
- 只从标准输入读、只往标准输出写；调试信息不得写入 stdout。

## 样例说明

- **样例 1**：初始全 0，`S 1 31` 把最高位置 1，状态变成 `0x80000000`，只有 1 个 1。
- **样例 2**：初始 `0x00000001`。`W 1` 交换高低 16 位后低位的那个 1 跑到了第 16 位（`0x00010000`），**1 的个数没变**；再 `S 1 0` 把第 0 位置 1，变成 `0x00010001`，共 2 个 1。两次查询都是 2。
- **样例 3**：第 1 个机柜 `0xFFFFFFFF` 清掉第 0 位 → 31 个 1；第 2 个机柜第 5 位翻转两次，等于没动，仍是 0。所以区间 1..2 是 31，单独第 2 个是 0。
- **样例 4**：第 1 个 `0x0000000F` 置第 4 位 → 5 个 1；第 2 个 `0x00FF0000` 是 8 个 1；第 3 个 `0xF0F0F0F0` 清第 4 位 → 15 个 1。合计 28，第 2 个机柜单独是 8。本样例还演示了**一个文件里连读两组**：第二组只有一个机柜，`W 1` 之后仍是 1 个 1。
- **样例 5**：`m = 0`，没有指令；全 1 的 32 位字有 32 个 1。注意此时中间那段指令行是空的，读入循环直接跳过即可。

## 实现提示

**三种操作都是"一位的开关"**，用掩码 `1u << b` 配合位运算即可，不要用十进制拆位：

- 置 1：`x |= (1u << b)`
- 清 0：`x &= ~(1u << b)`
- 取反：`x ^= (1u << b)`
- 交换高低 16 位：`x = (x << 16) | (x >> 16)`

**数一个数里有几个 1**（popcount）有两种写法，任选：

```c
int c = 0;
while (x) { x &= x - 1; ++c; }     // 每轮清掉最低位的 1，循环次数就是 1 的个数
// 或：__builtin_popcount(x)
```

**分步算法（5 步）**：

1. `while (scanf("%d %d %d", &n, &m, &q) == 3)` —— 用返回值判断是否读到 EOF，这是多组数据最稳的写法；
2. 读 n 个状态字用 `scanf("%x", &x)`（`%x` 认 `0x` 前缀，不用自己剥）；
3. 依次执行 m 条指令：先读一个字符串看首字母，`W` 只跟一个参数，`S/C/F` 跟两个；
4. **所有指令执行完之后**再算一遍每个机柜的 popcount，做一次前缀和 `pre[i] = pre[i-1] + popcount(state[i])`；
5. 每个查询直接 `pre[r] - pre[l-1]` 输出。

**为什么要把"统计"放在最后**：这样每次修改只花 O(1)，整体 O(n+m+q)；如果每来一个查询都重新数一遍，就是 O(n·q)，20 万 × 20 万必然超时。

**关键边界与易错点**：

- **`1u << 31` 必须是无符号**：写 `1 << 31` 在 32 位 `int` 上是溢出（未定义行为），会得到负数。
- **`W` 不能省略括号**：`x << 16 | x >> 16` 靠运算符优先级也能对，但 `x >> 16` 要用**交换前**的 `x`，写成 `x = x << 16; x |= x >> 16;` 就全错了。
- **多组数据的读法**：用 `while (scanf(...) == 3)` 或 `!= EOF`；不要用 `gets`（C11 起已删除，按 C++17 编译会失败）。
- **前缀和用 `long long`**：单柜最多 32 个 1，20 万柜最多 640 万，`int` 够用，但多组累加/边界写错时 `long long` 更保险。
- **`m = 0` 与 `q = 0`**：样例 5 就是 `m = 0`，读入循环一次都不进，别写成 `do...while`。

## 数据范围

- 1 ≤ n, m, q ≤ 2×10⁵（单组）
- 状态字范围 0 ~ 0xFFFFFFFF
- 1 ≤ i ≤ n，0 ≤ b ≤ 31，1 ≤ l ≤ r ≤ n
- 所有组的数据规模之和不超过单组上限的 3 倍

## 常见错误

1. **`1 << b` 用有符号 int**：b = 31 时结果是负数，`|=` 之后状态字高位异常。
2. **`W` 写成两步赋值**：先把 `x` 左移覆盖掉，再右移时用的是已经改过的值。
3. **每查一次重新数 popcount**：满规模直接 TLE。
4. **读十六进制自己写转换**：`%x` 已经认 `0x`，手写解析反而容易把前缀当数字。
5. **只读一组**：题目是多组到 EOF，只读第一组会少输出后面几组的结果。
6. **清位写反**：`x &= (1u << b)` 会把除这一位以外的所有位清掉，应该是 `&=` 取反的掩码。
7. **输出顺序错乱**：指令全部先执行、再统一查询；不要一边读一边答。
8. **交成 C++**：出现 `cout` / `vector` / `#include <iostream>` 时 `gcc` 按 C11 编译会直接失败。
