# P19 绝对值降序前列

> 难度：中等 · 计分：OI · **C++ 语言题**，单文件提交（main.cpp） · 构建：g++ -O2 -std=c++17 · 时限 1000ms / 256MB
> 题源：C++ 历年试卷编程题改编。本题题面自包含，无需查阅原卷。

## 题目背景

处理成绩涨跌、温度偏差、账户盈亏等数据时，经常需要挑出"偏离零点最远"的那些值，也就是绝对值最大的元素。

给定 n 个整数，请把它们按**绝对值从大到小**排序，并输出排序后的前 m 个元素。

## 输入格式

第一行两个整数 n 和 m（1 ≤ m ≤ n ≤ 100），分别表示元素个数和要取出的元素个数。
第二行 n 个整数 a₁ … aₙ（|aᵢ| ≤ 10⁹），用空格分隔。

## 输出格式

一行，输出排序后的前 m 个元素，用单个空格分隔。

排序规则：

1. 绝对值大的排在前面；
2. 绝对值相等时，数值小的排在前面（因此负数会排在对应正数之前，例如 -3 在 3 的前面）。

## 样例输入

```
6 4
-4 -3 -2 1 2 3
```

## 样例输出

```
-4 -3 3 -2
```

样例说明：各数绝对值为 4、3、2、1、2、3，降序排列后的元素依次是 -4(4)、-3(3)、3(3)、-2(2)、2(2)、1(1)，取前 4 个即 `-4 -3 3 -2`。

## 样例输入 2

```
5 5
5 -1 3 -3 0
```

## 样例输出 2

```
5 -3 3 -1 0
```

## 数据范围

- 1 ≤ m ≤ n ≤ 100
- |aᵢ| ≤ 10⁹

## 思路提示

用 `std::sort` 配合自定义比较器：先比较 `llabs(x)` 与 `llabs(y)`，不等时绝对值大的在前；相等时返回 `x < y`。注意用 `llabs` 而不是 `abs`，否则 long long 取值可能溢出。

## 常见错误

1. 只按绝对值排序，绝对值相等时顺序不确定（-3 与 3 谁先谁后）。
2. 比较器写成 `return ax >= ay`，不满足严格弱序，`sort` 行为未定义。
3. m 可能等于 n，输出循环不要写死上界。
