# P28 完数判定

> 难度：简单 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 2000ms / 256MB
> 题源：情境拓展 ·《趣味数学及编程拓展》1.5.1 完全数。本题题面自包含，无需查阅原卷。

## 题目背景

完全数是指恰好等于自身所有真因子之和的正整数。真因子指能整除它且严格小于它的正整数（包括 1，不包括自身）。

例如 6 的真因子是 1、2、3，和为 6；28 的真因子是 1、2、4、7、14，和为 28。

给定正整数 n，请判断它是否为完全数。

## 输入格式

一行，一个正整数 n（1 ≤ n ≤ 10⁸）。

## 输出格式

一行：若 n 是完全数，输出 `YES`；否则输出 `NO`。全部大写。

## 样例输入

```
6
```

## 样例输出

```
YES
```

## 样例输入 2

```
28
```

## 样例输出 2

```
YES
```

## 样例输入 3

```
12
```

## 样例输出 3

```
NO
```

样例说明：12 的真因子为 1、2、3、4、6，和为 16 ≠ 12。

## 数据范围

- 1 ≤ n ≤ 10⁸

## 思路提示

从 d = 2 试除到 d*d ≤ n。每找到一个因子 d 就把它累加；同时令 other = n/d，若 other != d 也累加（成对累加，避免平方因子被重复计算）。真因子和初值为 1（n > 1 时 1 一定是真因子）。n = 1 时没有真因子，直接输出 NO。

## 常见错误

1. 把 n 自身也累加进去，导致任何数都判定为 YES。
2. 平方因子（如 36 的 6）被累加两次。
3. n = 1 时输出 YES——1 的真因子和是 0，不是完全数。
4. 用 int 存因子和，大数时溢出。
