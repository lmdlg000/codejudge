# P34 迷宫最短通道

> 难度：困难 · 计分：OI · **C++ 语言题**，单文件提交（main.cpp） · 构建：g++ -O2 -std=c++17 · 时限 1000ms / 256MB

> 题源：情境拓展 ·《趣味数学及编程拓展》7.8 迷宫最短通道。本题题面自包含，无需查阅原卷。

## 题目背景

迷宫求解是广度优先搜索的经典应用：把迷宫中的每个可通行格子看作图上的结点，相邻的空格之间有边相连，从起点出发逐层扩展，就能找到到达终点所需步数最少的路线。

## 输入格式

第一行两个整数 n m（1 ≤ n,m ≤ 20）。接下来 n 行，每行一个长度为 m 的字符串，字符为 '.'（空地）、'#'（墙）、'S'（起点）、'T'（终点）。输入保证恰有一个 S 和一个 T。

## 输出格式

一行，一个整数，表示从 S 到 T 的最少移动步数（每步上下左右移动一格，不能穿墙）；若不可达输出 -1。

## 样例输入

```
3 3
S.#
...
#.T
```

## 样例输出

```
4
```

## 样例输入 2

```
2 2
S.
.T
```

## 样例输出 2

```
2
```

## 数据范围

- 1 ≤ n,m ≤ 20；迷宫恰有一个 S 和一个 T
- 判题采用 trim 比对：忽略行末与整体首尾空白，行内空格敏感。

## 思路提示

从 S 出发做 BFS：队列里存当前坐标，dist 记录步数，每走到一个新格就记 dist+1。因为 BFS 按层扩展，第一次到达 T 时的步数就是最短路。注意越界与墙的判断。

## 常见错误

1. 起点终点相邻时答案为 1，S=T 时答案为 0
2. 不可达要输出 -1
3. 输入行是连续字符串，用 cin >> 读取
