# P34 百钱百鸡

> 难度：中等 · 计分：ACM · **C 语言题**，单文件提交（main.c） · 构建：gcc -O2 -std=c11 · 时限 1000ms / 256MB

> 题源：情境拓展 ·《趣味数学及编程拓展》4.2.1 百钱百鸡问题。本题题面自包含，无需查阅原卷。

## 题目背景

这是《孙子算经》流传下来的经典问题：用一百钱买一百只鸡，公鸡每只五钱、母鸡每只三钱、小鸡三只一钱，问公鸡、母鸡、小鸡各买多少只。把总钱数与总只数 generalize 后，请枚举出所有可能的购买方案。

## 输入格式

一行，两个整数 m 和 n，分别表示总钱数和总只数。

## 输出格式

第一行一个整数 k，表示方案数；接下来 k 行，每行三个整数 x y z，分别表示公鸡、母鸡、小鸡的只数，按 x 升序、x 相同按 y 升序排列。无解时只输出 0。

## 样例输入

```
100 100
```

## 样例输出

```
4
0 25 75
4 18 78
8 11 81
12 4 84
```

## 样例输入 2

```
50 50
```

## 样例输出 2

```
2
2 9 39
6 2 42
```

## 数据范围

- 0 ≤ m,n ≤ 1000，保证方案数不超过 1000
- 判题采用 trim 比对：忽略行末与整体首尾空白，行内空格敏感。

## 思路提示

枚举公鸡 x 与母鸡 y，小鸡 z = n - x - y 由总只数确定；只要 z 能被 3 整除且总价等于 m 即为一组解。循环上界可用 x*5<=m 与 x+y<=n 提前剪枝。

## 常见错误

1. 小鸡必须三只一钱，z 需被 3 整除
2. 输出顺序：方案数单独一行，再逐行 x y z
3. 无解时只输出 0
