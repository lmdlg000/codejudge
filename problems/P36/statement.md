# P36 数字三角形取最大和

> 难度：困难 · 计分：OI · **C++ 语言题**，单文件提交（main.cpp） · 构建：g++ -O2 -std=c++17 · 时限 1000ms / 256MB

> 题源：情境拓展 ·《趣味数学及编程拓展》5.3.1 巧妙建模（数字三角形）。本题题面自包含，无需查阅原卷。

## 题目背景

数字三角形中，从顶端出发每次只能向左下或右下走一步，直到落到底边。如何选出一条路径使沿途数字之和最大？自底向上逐层合并，可以把指数级的枚举压缩成一次线性递推。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 100）。接下来 n 行，第 i 行有 i 个整数，表示数字三角形第 i 行的元素。

## 输出格式

一行，一个整数，表示从顶部走到底部路径上数字之和的最大值。

## 样例输入

```
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```

## 样例输出

```
30
```

## 样例输入 2

```
3
1
2 3
4 5 6
```

## 样例输出 2

```
10
```

## 数据范围

- 1 ≤ n ≤ 100，|a[i][j]| ≤ 1000
- 判题采用 trim 比对：忽略行末与整体首尾空白，行内空格敏感。

## 思路提示

自底向上做动态规划：dp[j] 表示从当前行第 j 列走到底的最大和。从最后一行往上递推，dp[j] = a[i][j] + max(dp[j], dp[j+1])，只需一维数组。

## 常见错误

1. 数字可能为负，dp 初值不能设为 0（自底向上第一行直接由 a 赋值，无此问题）
2. 第 i 行有 i 个数，输入格式要按行读
3. 结果可能超过 int，用 long long
